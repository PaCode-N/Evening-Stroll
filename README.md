# Evening Stroll 🌙

An interactive choice-driven narrative game where your decisions shape the course of the story.

## About

This was my first beginner project in Python, created to practice the basics of programming through a small interactive story.

The game uses user input, conditional statements, loops, random numbers and different story paths leading to multiple endings.
